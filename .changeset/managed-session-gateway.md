Enable AI Gateway with `sandbox create --ai`, or add `--image my-image` for Gateway access without rewriting custom image configuration. On the universal image, prepare all four coding agents or launch one with `sandbox create --ai codex`. Add opt-in backend-managed AI Gateway credentials per session, with saved or host-supplied keys as a fallback. Managed credentials require the backend rollout.
